# Onde fica a documentação da API pública (URL base, autenticação por token, como gerar o token)?

Não encontrei, nestes espaços, o link da documentação pública nem os detalhes sobre URL base, formato de autenticação ou geração do token.

Há guias que descrevem recursos específicos da API, como [Distribuição via API](/guide/documentacao/apps/distribuicao-de-atendimentos/distribuicao-via-api.md). A documentação disponível também informa que chaves de API sem uso por mais de 15 dias são excluídas automaticamente ([22/09/2026](/guide/novidades-do-sistema/setembro-de-2026/22-09-2026.md)). Esses materiais não explicam como gerar a chave nem apresentam a URL base pública.
