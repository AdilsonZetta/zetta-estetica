# É possível adicionar um ícone ou link de aplicativo externo personalizado no menu da plataforma, abrindo em nova aba ou iframe? Existe SSO?

A documentação não confirma a possibilidade de adicionar um ícone ou link externo personalizado ao menu da FLW Chat, nem de abrir esse destino em nova aba ou iframe. Também não especifica suporte a SSO.

A plataforma oferece integrações por API e webhooks, além de Make.com e N8N, conforme a página de [Integrações](/guide/documentacao/ajustes/integracoes.md). O [Widget de Atendimento](/guide/documentacao/ajustes/integracoes/widget-de-atendimento.md) é instalado em um site para captar e encaminhar visitantes; a documentação não o descreve como forma de embutir um sistema externo dentro da plataforma.

Assim, a integração da clínica via API e webhooks está alinhada às integrações documentadas, mas o ícone no menu, o iframe e o SSO não estão detalhados.
